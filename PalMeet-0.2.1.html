PalMeet 0.2.1

  • The copilot, summaries and spelling fixes now use an AI provider that works. If the one you picked has no API key (or its CLI is logged out), PalMeet uses your Claude Code login, or another working provider, and says so in Settings → AI Providers.
  • New **Meeting context** box in the live view: type the agenda, ticket, who's who, names and terms at any time. The copilot uses it immediately; the summary and spelling fixes use it afterwards. Saved with the meeting as context.md.
